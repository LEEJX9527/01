macOS 安装

推荐终端一行命令安装——命令行 curl 下载的文件不带隔离属性，Gatekeeper 不检查，未签名 app 全程零警告： 

curl -fsSL https://raw.githubusercontent.com/LEEJX9527/01/main/scripts/install-desktop.sh | sh

浏览器直接下载 DMG 的用户，安装后首次打开被拦截时，二选一：

  1. 系统设置 → 隐私与安全性 → 下拉到「安全性」一节 → 点 Calorie Studio 旁的「仍要打开」；
  2. 或终端执行 xattr -cr /Applications/Calorie\ Studio.app 后正常打开。

Windows 安装

  1. 运行下载的 -setup.exe，按引导完成安装；
  2. 首次运行如出现蓝色「Windows 已保护你的电脑」提示：点「更多信息」→「仍要运行」。

常见问题

  • Intel Mac 能装吗？ 目前只提供 Apple Silicon 包，Intel 机型建议使用在线版。
  • 需要填 API 密钥吗？ 不需要。默认「本地食物库」模式完全离线；想用 AI 识别照片，再在设置里配置自己的密钥。
  • 我的数据在哪？ 全部在本地：桌面版存应用配置目录，在线版存浏览器 IndexedDB，可随时导出 JSON 备份。
